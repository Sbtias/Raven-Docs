Núcleo, bucle y memoria

El header raven_core.h contiene el ciclo de vida, el bucle de frames, los handles, los errores, las acciones, los timers, las tareas y el montón propio de Raven.

Arrancar y parar

#include <Raven.h>

int main(void) {
    RInitDesc desc = {0};
    desc.backend  = R_BACKEND_VULKAN;
    desc.app_name = "Mi editor";
    if (!Rinit_ex(&desc)) {
        return 1;
    }

    /* ventanas y widgets... */

    while (Rwait_frame(-1.0)) {
        /* el bucle de la aplicación: aquí van las tareas periódicas */
    }

    Rshutdown();
    return Rget_exit_code();
}
FunciónQué hace
Rinit / Rinit_exArranca la librería con valores por defecto o con una RInitDesc explícita (backend, nombre, headless, allocator…). Devuelve R_FALSE si no puede.
Rdraw_frameProduce un frame: procesa eventos pendientes sin esperar, ejecuta tareas, anima, mide, pinta y presenta. Devuelve R_FALSE cuando toca salir.
Rwait_frame(seconds)Igual, pero antes duerme hasta que haya algo que hacer: un evento del sistema, una tarea, un timer o un frame que pedir. Con -1.0 espera indefinidamente.
Rquit(code)Hace que Rdraw_frame y Rwait_frame devuelvan R_FALSE. Es seguro llamarlo desde otro hilo.
Rget_exit_codeEl código dado a Rquit, o 0 si se cerró la última ventana.

Handles y errores

Ventanas, widgets, texturas, fuentes y documentos son Rid: un identificador opaco. R_INVALID_ID representa “ninguno”. Las funciones que aceptan un Rid comprueban que siga vivo; una llamada con un handle inválido no rompe el proceso y se reporta por el callback de errores.

static void on_error(RError code, RSeverity severity, const char* detail) {
    fprintf(stderr, "[raven] %s\n", detail);
}

Rerror_set_callback(on_error);

Acciones, timers y tareas

Las acciones son el puente entre el XML (OnClicked="file.save") y el código. Un mismo nombre puede tener varias implementaciones; se ejecutan todas.

Raction_bind("file.save", on_save, app);
Raction_fire("file.save", editor);
GrupoFunciones
TimersRtimer_create, Rtimer_destroy, Rtimer_is_valid. Intervalo en segundos, repetible o de un disparo, callback en el hilo de UI.
TareasRtask_post (ejecuta una función en el hilo de UI), Rtask_run_async (en un worker) y Rparallel_for (reparte un rango entre los workers).
HilosRwake_up, Rget_time, Rwindow_request_redraw, Rquit y las funciones de memoria son seguras desde otros hilos.

Memoria

Raven no llama a malloc: toma memoria del sistema por regiones de 4 MB y la reparte con su propio heap (TLSF: tiempo constante y vecinos fusionados al liberar). Los decodificadores de fuente e imagen incluidos también lo usan.

RAllocator mio = { my_alloc, my_realloc, my_free, my_data };
Rset_allocator(&mio);                 /* antes de Rinit: todo pasa por tus funciones */

RMemoryStats stats;
Rmemory_get_stats(&stats);            /* bloques, bytes en uso, pico, tomado del sistema */
Rmemory_check();                      /* recorre el heap y verifica su estructura       */
Rmemory_trim();                       /* devuelve al sistema las regiones vacías        */

Rset_allocator(Rallocator_get_system()) o RAVEN_ALLOCATOR=system selecciona malloc, que es lo que siguen Valgrind y los perfiladores de heap (también es el defecto en una compilación con AddressSanitizer).

Widgets y layout

El árbol de widgets se conserva entre frames. Un widget nace sin ventana; se muestra cuando se añade a un padre que ya pertenece a una. Rwidget_create recibe un RWidgetType; para los tipos más comunes hay atajos como Rlabel_create, Rbutton_create o Rtext_editor_create.

Rid root  = Rwidget_create(R_WIDGET_VBOX);
Rid title = Rwidget_add_child(root, Rlabel_create("Hola"));
Rid field = Rwidget_add_child(root, Rwidget_create(R_WIDGET_TEXT_INPUT));
Rid btn   = Rwidget_add_child(root, Rbutton_create("Saludar"));

Rwidget_set_name(field, "nombre");
Rpanel_set_spacing(root, 12.0f);
Rslot_set_padding(root, 16, 16, 16, 16);

El slot del hijo

El layout no se configura en el padre sino en el slot de cada hijo: relleno, alineación, tamaño, columnas, anclas, dock o título de pestaña. Es el equivalente a Slot.* en XML.

Rslot_set_padding(btn, 8, 4, 8, 4);
Rslot_set_halign(btn, R_HALIGN_RIGHT);
Rslot_set_valign(btn, R_VALIGN_CENTER);
Rslot_set_fill(btn, 1.0f);
Rslot_set_grid(btn, 1, 0);

Las listas enormes no necesitan crear un widget por fila: Rlist_view_set_virtual_items(list, count, callback, user) pide el texto de cada fila visible cuando hace falta. Es el mismo patrón que usan el editor, el grafo y la línea de tiempo para escalar.

Temas, fuentes y recursos

Rtheme_set_style_metric("Button", NULL, R_METRIC_CORNER_RADIUS, 16);
Rtheme_use(Rtheme_load("themes/ocean.xml"));

Rid icon = Rtexture_create_from_file("icons/save.png");

XML y documentos

raven_xml.h es a la vez el cargador de interfaces y una API de documentos: se puede leer, recorrer, modificar, serializar y volver a construir un árbol XML sin tocar un archivo. La referencia XML explica los tags y atributos.

Rid window = Rwindow_create_from_xml_file("editor.xml");
Rid panel  = Rwidget_create_from_xml(xml, strlen(xml));

RXmlError error;
Rid doc = Rxml_document_parse("<VBox><Label Text='x'/></VBox>", 40, &error);
if (!doc) {
    fprintf(stderr, "línea %d: %s\n", error.line, error.message);
}

Rid root  = Rxml_document_get_root(doc);
Rid label = Rxml_node_add_child(root, "Label", -1);
Rxml_node_set_attribute(label, "Text", "desde C");
Rid built = Rxml_document_create_widget(doc);
Rxml_document_destroy(doc);

Herramientas, diálogos y dibujo

El resto de la API cubre las piezas que convierten a Raven en una base para editores: herramientas creativas, diálogos del sistema, viewports, dibujo inmediato, shaders, Vulkan y backends.

Herramientas creativas

En raven_tools.h: el selector de color, la línea de tiempo, el grafo de nodos y el editor de bloques. Tienen 173 funciones entre modelos, callbacks, vistas y utilidades de color.

Diálogos y archivos

raven_dialogs.h usa los diálogos del sistema cuando existen (Windows: diálogos comunes; Linux: zenity o kdialog) y, si no, un diálogo de Raven construido sobre FileBrowser.

RFileDialogDesc desc = {0};
desc.parent = window;
desc.title  = "Abrir";
desc.filters = filtros;
desc.filter_count = 2;
const char* path = Rfile_dialog_open(&desc);   /* NULL si se cancela */

if (Rmessage_box(window, "Salir", "¿Descartar los cambios?",
                 R_MESSAGE_OK_CANCEL) == R_MESSAGE_RESULT_OK) {
    Rquit(0);
}

Viewports y dibujo

raven_viewport.h muestra una textura, dibuja dentro del render pass de Raven o crea una ventana hija nativa. raven_draw.h es la API de dibujo inmediato para widgets personalizados.

/* 1. textura: cualquier imagen, como un widget */
Rviewport_set_texture(viewport, texture);

/* 2. callback de dibujo: tus llamadas Vulkan en el render pass de la ventana */
Rviewport_set_draw_callback(viewport, on_draw, app);

/* 3. ventana hija nativa: OpenGL, Direct3D, lo que sea */
Rviewport_set_native(viewport, R_TRUE);
Rviewport_get_native_handle(viewport, &native);
