¿Qué es Raven?

Raven es una librería de interfaz gráfica retained-mode escrita en C11. El árbol de widgets se conserva entre frames; solo se vuelve a medir, pintar y presentar lo que cambió. La aplicación escribe su propio bucle y pide un frame cada vez con Rdraw_frame() o Rwait_frame(). Debajo, Raven abre ventanas nativas con Win32, X11 o Cocoa, y dibuja con Vulkan (MoltenVK en macOS).

⚙

Pequeña y autónoma

No enlaza Vulkan ni depende de Qt, GTK o Electron. Tiene su propio asignador, su decodificador de imágenes, sus fuentes y su renderer. Un único header: <Raven.h>.

❖

Interfaz declarativa

Escribe ventanas en XML, con Slot.*, acciones, temas y tags propios. O compila el XML y el código en un solo archivo con ravenc (XMLC) en cualquiera de los ocho lenguajes.

▣

Herramientas de autor

Editor de texto con sintaxis, docking con pestañas desprendibles, grafo de nodos, línea de tiempo, selector de color, editor de bloques, visores web y viewports para tu propio renderer.

Lo que trae

◆ Layout Slate

VBox, HBox, Grid, Overlay, Border, Canvas, ScrollBox, Splitter, WrapBox, Switcher, TabView, Expander y DockArea. Cada hijo lleva su slot: relleno, alineación, tamaño.

◆ Ventanas nativas

Win32, X11 y Cocoa. Header bar personalizada, ventanas transparentes, backdrop blur/acrylic/mica, opacidad y arrastre de archivos.

◆ Materiales de cristal

Solid, Glass, FrostedGlass y TintedGlass. Los paneles se ven a través, se difuminan y refractan lo que hay detrás, con temas claros y oscuros.

◆ Animaciones con springs

Los controles se estiran, rebotan y se asientan solos. Transiciones Fade, Pop, Zoom, Fly, Drop, Slide; motion Snappy, Smooth, Bouncy, Wobbly.

◆ Texto completo

Editor multilínea con resaltado para 13 lenguajes, autocompletado, pares de brackets, marcadores de error, Markdown, RTL, shaping árabe y emoji a color.

◆ Accesibilidad

UI Automation en Windows, NSAccessibility en macOS, AT-SPI en Linux. Escala de texto, alto contraste, filtros de color y reducción de movimiento.

◆ i18n

Tablas CSV, Rtr("clave"), plurales CLDR, formato de números por idioma y layouts que se reflejan automáticamente en RTL.

◆ Multihilo

Hilo de render dedicado, job system, tareas asíncronas, decodificación de imágenes en segundo plano y pintado paralelo de árboles grandes.

◆ Viewports

Muestra una textura, dibuja dentro del render pass de Raven o crea una ventana hija nativa para OpenGL, Direct3D o lo que necesites.

◆ Web real

raven_web conduce un Chromium ya instalado (Edge en Windows) por el protocolo DevTools: página real, entrada real, JavaScript en ambos sentidos.

◆ Recarga en vivo

Guarda el XML, el tema o las traducciones y la interfaz se actualiza conservando handles, callbacks, scroll y texto escrito.

◆ Tu propio backend

El renderer está detrás de una tabla de funciones. Puedes registrar otro backend o usar el nulo para tests headless sin GPU.

Visto en acción

Empieza en dos minutos

Con este paquete precompilado para Windows (MinGW-w64 x64, estático) solo necesitas un compilador de MinGW y CMake. La guía de instalación explica también cómo compilar desde el código fuente y cómo usar el paquete desde Visual Studio.

#include <Raven.h>

static void on_clicked(Rid button, void* user) {
    Rquit(0);
}

int main(void) {
    Rinit(R_BACKEND_VULKAN);

    Rid window = Rwindow_create("Hello", 420, 220, R_WINDOW_DEFAULT);
    Rid box = Rwidget_create(R_WIDGET_VBOX);
    Rpanel_set_spacing(box, 12);
    Rslot_set_halign(box, R_HALIGN_CENTER);
    Rslot_set_valign(box, R_VALIGN_CENTER);
    Rwindow_set_content(window, box);

    Rwidget_add_child(box, Rlabel_create("Hello from Raven"));
    Rid button = Rwidget_add_child(box, Rbutton_create("Quit"));
    Rbutton_set_clicked_callback(button, on_clicked, NULL);

    while (Rwait_frame(-1.0)) {}
    Rshutdown();
    return 0;
}
cmake_minimum_required(VERSION 3.16)
project(hello C)

set(CMAKE_PREFIX_PATH "C:/ruta/a/raven-windows-mingw-x64-static")
find_package(raven REQUIRED)

add_executable(hello main.c)
target_link_libraries(hello PRIVATE raven::raven)

¿Prefieres declarar la interfaz? El mismo programa en XML:

<Window Title="Hello" Width="420" Height="220">
    <VBox Spacing="12" Slot.HAlign="Center" Slot.VAlign="Center">
        <Label>Hello from Raven</Label>
        <Button Text="Quit" OnClicked="app.quit"/>
    </VBox>
</Window>
